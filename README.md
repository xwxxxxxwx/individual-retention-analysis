# 用户留存分析项目

> 个人项目 | Python | 数据分析 | 用户留存

## 项目简介

基于真实业务数据的用户留存分析项目，通过数据清洗、探索性分析和可视化，深入研究用户留存率、用户行为模式和产品优化方向。

项目解决的核心问题：量化用户留存情况，识别不同用户群体的留存差异，挖掘影响留存的关键因素，为产品优化提供数据支撑。

## 技术栈

- 编程语言：Python 3
- 数据处理：Pandas, NumPy
- 可视化：Matplotlib, Seaborn, Plotly
- 开发环境：Jupyter Notebook

## 分析内容

### 数据处理
- 原始数据清洗和预处理
- 缺失值处理
- 数据格式转换
- 特征工程

### 分析维度
- 用户次日 / 7 日 / 30 日留存率计算
- 不同用户分群的留存对比（按渠道、地域、用户层级等）
- 用户行为路径分析
- 留存影响因素分析
- 留存趋势和衰减曲线分析

### 可视化
- 留存曲线（Cohort Analysis 同期群分析）
- 热力图展示
- 趋势分析图表
- 对比分析图表
